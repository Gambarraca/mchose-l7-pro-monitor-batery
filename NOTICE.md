The tray interface, polling loop, battery icon, and Windows startup code were written specifically for this project; this is not a copy or port of the Mouse Tray Charge application. To read the MCHOSE L7 Pro, this app uses the public HID protocol details documented in Mouse Tray Charge (https://github.com/Fan4Metal/mouse_tray), including the device identifiers and battery-report format. The protocol itself was not independently discovered or reverse-engineered for this project.
